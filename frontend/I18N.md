# Sistema de Internacionalización (i18n)

## 🌍 ¿Qué se ha implementado?

Se ha añadido un sistema completo de cambio de idioma a tu portfolio con soporte para **español** (por defecto) e **inglés**.

## 📁 Estructura Creada

```
src/
├── locales/
│   ├── es.ts          # Traducciones en español
│   └── en.ts          # Traducciones en inglés
├── context/
│   └── LanguageContext.tsx   # Contexto y provider de idioma
├── components/
│   ├── Navbar.tsx     # Selector de idioma en navbar
│   ├── MobileNav.tsx  # Selector de idioma en menu móvil
│   ├── Hero.tsx       # Textos traducidos
│   ├── About.tsx      # Textos traducidos
│   ├── Skills.tsx     # Textos traducidos
│   ├── Projects.tsx   # Textos traducidos
│   ├── Contact.tsx    # Textos traducidos
│   └── Footer.tsx     # Textos traducidos
├── pages/
│   ├── ProjectDetails.tsx   # Textos traducidos
│   └── NotFound.tsx         # Textos traducidos
└── App.tsx            # LanguageProvider envolvente
```

## 🎯 Características

✅ **Selector de idioma en el navbar** - Dropdown con opciones ES/EN
✅ **Persistencia** - El idioma seleccionado se guarda en localStorage
✅ **Español por defecto** - La página comienza en español
✅ **Contexto de React** - Acceso global a traducciones sin prop drilling
✅ **Totalmente traducido** - Todos los textos visibles están traducidos
✅ **Responsive** - Funciona en desktop y móvil

## 🔧 Cómo usar

### Para acceder a las traducciones en un componente:

```typescript
import { useLanguage } from '@/context/LanguageContext';

export const MyComponent = () => {
  const { language, setLanguage, t } = useLanguage();
  
  return <h1>{t.hero.title}</h1>; // Acceso a traducciones
};
```

### Para agregar nuevas traducciones:

1. Añade las nuevas claves en `src/locales/es.ts`
2. Añade las traducciones en `src/locales/en.ts`
3. Úsalas en tus componentes con `t.tuClave.subClave`

**Ejemplo:**
```typescript
// es.ts
export const es = {
  nav: {
    about: 'Sobre Mí',
    ...
  },
  miSeccion: {
    titulo: 'Mi Título',
  }
};

// Usar en componente
const { t } = useLanguage();
<h1>{t.miSeccion.titulo}</h1>
```

## 💾 Persistencia

El idioma seleccionado se guarda automáticamente en `localStorage` con la clave `'language'`. Cuando el usuario vuelva a visitar la página, se restaurará el idioma que tenía seleccionado.

## 🎨 Selector en el Navbar

El selector de idioma aparece en:
- **Desktop**: En la barra de navegación, junto al botón de Resume
- **Mobile**: En el menú desplegable, junto al botón de Resume

## 📝 Notas

- Las traducciones están organizadas por secciones/componentes para fácil mantenimiento
- El contexto maneja la carga del idioma guardado antes de renderizar
- No se necesita instalar librerías adicionales como `i18next`
